# pv-battery-optimizer
Intelligente Home-Assistant-Integration zur Optimierung von PV-Speichersystemen. Steuere deine Batterieladung proaktiv basierend auf PV-Prognose, Hausverbrauch und Strompreisen. Maximiert die EEG-Vergütung durch intelligentes, tageszeitabhängiges Lademanagement und schont dabei den Akku
